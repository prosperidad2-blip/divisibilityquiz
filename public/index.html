Production REST API Routes

GET /api/health

Verifies Express uptime & Firestore connection status.

POST /api/admin/verify

Server-side Admin PIN verification (uses ADMIN_PIN env var).

GET & POST /api/records

Lists or upserts learner progress directly into Firestore.

DELETE /api/records/:docId & /api/records

Admin PIN-protected single or batch Firestore record deletion.

Deploy to Render in 3 Steps

  1. Extract the downloaded ZIP and push the folder to a new GitHub repository.
  2. On Render.com, click New + → Web Service, connect your repo, set Build Command to npm install and Start Command to npm start.
  3. In Render Environment Variables, add FIREBASE_SERVICE_ACCOUNT_JSON (paste your Firebase service account JSON) and ADMIN_PIN=1234.

            

        


    


    
    

        

            

                
 Divisibility Rules Quick Guide

                
            

            

                
Divisible by 2: Last digit is even (0, 2, 4, 6, 8).

                
Divisible by 3: Sum of digits is a multiple of 3.

                
Divisible by 4: Last two digits are 00 or divisible by 4.

                
Divisible by 5: Last digit is 0 or 5.

                
Divisible by 6: Divisible by both 2 and 3.

                
Divisible by 8: Last three digits are 000 or divisible by 8.

                
Divisible by 9: Sum of digits is a multiple of 9.

                
Divisible by 10: Last digit is 0.

                
Divisible by 11: Difference of alternating digit sums is 0 or a multiple of 11.

                
Divisible by 12: Divisible by both 3 and 4.
